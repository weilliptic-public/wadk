# Examples

Examples are grouped by the SDK surface they demonstrate:

- `audit/`: direct audit logging and HTTP audit streaming examples.
- `auth/`: signature verification helpers and standalone auth examples.
- `langchain/`: LangChain agent integrations.
- `mcp/`: MCP servers, clients, and secured MCP audit examples.
- `tracer/`: trace and graph-trace examples.
- `wallet/`: wallet, derived-account, and secure-wallet examples.
- `google-adk/`, `adk-ported/`, `strands/`: framework-specific agent examples.
- `agents_fleet/`, `customer_support_triage/`: larger end-to-end sample apps.
